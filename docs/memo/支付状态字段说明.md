# PayNow 支付状态字段补充说明

> 本文档补充说明 Payout API 的状态字段定义和支付成功判断条件

---

## 状态字段详解

### cryptoPaymentStatus（加密货币支付状态）

| 值 | 说明 | 前端处理 |
|----|------|---------|
| `pending` | 加密货币支付待确认 | 继续轮询 |
| `verified` | ✅ 加密货币支付已验证 | 检查 fiatPaymentStatus |
| `failed` | ❌ 加密货币支付失败 | 显示失败页面 |
| `expired` | ⏰ 订单已过期 | 显示过期提示 |

### fiatPaymentStatus（法币支付状态）

| 值 | 说明 | 前端处理 |
|----|------|---------|
| `pending` | 法币支付待处理 | 继续轮询 |
| `processing` | 🔄 法币支付处理中 | 继续轮询 |
| `success` | ✅ 法币支付成功 | 检查 cryptoPaymentStatus |
| `failed` | ❌ 法币支付失败 | 显示失败页面 |

---

## ⭐ 支付成功判断条件

交易**必须同时满足两个条件**才算成功：

```typescript
if (cryptoPaymentStatus === 'verified' && fiatPaymentStatus === 'success') {
  // ✅ 支付成功
  showSuccessPage();
}
```

### 为什么需要同时检查两个状态？

1. **`cryptoPaymentStatus === 'verified'`**
   - 确认用户已成功发送加密货币到收款地址
   - 链上交易已被后端验证

2. **`fiatPaymentStatus === 'success'`**
   - 确认后端已成功将法币转给 PayNow 收款方
   - 整个支付链路完成

**只有两者都成功，才能确保：**
- ✅ 用户的加密货币被接收
- ✅ 商户收到法币

## 轮询逻辑示例

```typescript
async function pollPayoutStatus(payoutId: string): Promise<'success' | 'failed' | 'timeout'> {
  const maxAttempts = 60;
  const interval = 3000; // 3秒

  for (let i = 0; i < maxAttempts; i++) {
    const record = await getPayoutRecord(payoutId);

    if (record.code === 200 && record.data) {
      const { cryptoPaymentStatus, fiatPaymentStatus } = record.data;

      // ✅ 支付成功
      if (cryptoPaymentStatus === 'verified' && fiatPaymentStatus === 'success') {
        return 'success';
      }

      // ❌ 支付失败
      if (cryptoPaymentStatus === 'failed' || fiatPaymentStatus === 'failed') {
        return 'failed';
      }

      // ⏰ 订单过期
      if (cryptoPaymentStatus === 'expired') {
        return 'failed';
      }

      // 其他状态（pending/processing）继续轮询
    }

    await sleep(interval);
  }

  return 'timeout'; // 3分钟超时
}
```

## createPayout 参数说明

创建 Payout 订单时，**必须明确指定** `cryptoCurrency` 和 `cryptoChain`：

```typescript
const response = await createPayout({
  // ... 其他参数
  cryptoCurrency: 'USDC',    // ⭐ 必须指定 'USDC' 生成 USDC 支付订单
  cryptoChain: 'SOLANA',      // ⭐ 必须指定 'SOLANA' 生成 Solana 链订单
  // ...
});
```

**为什么需要明确指定？**
- 后端根据这两个参数决定生成哪种加密货币的支付订单
- 不同链和币种的处理逻辑不同
- 确保前后端一致性

## 状态流转示意图

```
[创建订单]
  ↓
cryptoPaymentStatus: pending
fiatPaymentStatus: pending
  ↓
[用户发送交易]
  ↓
cryptoPaymentStatus: pending → verified
fiatPaymentStatus: pending
  ↓
[后端处理法币转账]
  ↓
cryptoPaymentStatus: verified
fiatPaymentStatus: pending → processing → success
  ↓
✅ 支付完成
```

## 错误场景处理

| 场景 | cryptoPaymentStatus | fiatPaymentStatus | 前端处理 |
|------|---------------------|-------------------|---------|
| 用户交易失败 | `failed` | `pending` | 显示"支付失败，请重试" |
| 法币转账失败 | `verified` | `failed` | 显示"法币转账失败，请联系客服" |
| 订单过期 | `expired` | `pending` | 显示"订单已过期，请重新扫码" |
| 轮询超时 | `pending` | `pending` | 显示"确认中，请稍后查询" + 提供链上查询链接 |
