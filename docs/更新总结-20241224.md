## 🔑 关键信息总结

### 1. createPayout 参数要求

```typescript
const response = await createPayout({
  // ...其他参数
  cryptoCurrency: 'USDC',    // ⭐ 必须指定 'USDC'
  cryptoChain: 'SOLANA',      // ⭐ 必须指定 'SOLANA'
  // 不需要传 paymentAddress
});
```

### 2. 状态字段完整枚举

| 字段 | 可能值 |
|------|--------|
| `cryptoPaymentStatus` | `'pending'` \| `'verified'` \| `'failed'` \| `'expired'` |
| `fiatPaymentStatus` | `'pending'` \| `'processing'` \| `'success'` \| `'failed'` |

### 3. 支付成功判断条件

```typescript
// ⭐ 必须同时满足两个条件
if (cryptoPaymentStatus === 'verified' && fiatPaymentStatus === 'success') {
  // ✅ 支付成功
}
```

**为什么需要同时检查？**
- `cryptoPaymentStatus === 'verified'` → 确认链上交易已验证
- `fiatPaymentStatus === 'success'` → 确认法币已转给 PayNow 收款方

### 4. 完整轮询逻辑

```typescript
for (let i = 0; i < 60; i++) {
  const record = await getPayoutRecord(payoutData.id);

  if (record.code === 200 && record.data) {
    const { cryptoPaymentStatus, fiatPaymentStatus } = record.data;

    // 成功
    if (cryptoPaymentStatus === 'verified' && fiatPaymentStatus === 'success') {
      return 'success';
    }

    // 失败
    if (cryptoPaymentStatus === 'failed' || fiatPaymentStatus === 'failed') {
      return 'failed';
    }

    // 过期
    if (cryptoPaymentStatus === 'expired') {
      return 'failed';
    }
  }

  await sleep(3000);
}
```

## ⚠️ 重要提示

1. **状态检查**：必须同时检查 `cryptoPaymentStatus` 和 `fiatPaymentStatus`
2. **参数指定**：createPayout 时必须明确指定 `cryptoCurrency` 和 `cryptoChain`
3. **轮询间隔**：建议 3 秒轮询一次，最多 3 分钟（60次）
4. **错误处理**：需要区分 failed、expired 和 timeout 三种错误状态
